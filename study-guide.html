Build ladder — start at the top

  1. Start
    A third template. New brief: opening line, 4 fields, wrap prompt.Zero audio risk. Proves prompt skill.
  2. Start
    Transcript library. List + search over saved .txt files.Turns a dead folder into a surface.
  3. Next
    Ephemeral tokens. Wire /api/token so the browser never sees the key.The one change that makes this deployable.
  4. Next
    Auto field-tick. Function calling in setup ticks the checklist.Compare auto vs manual on 5 runs.
  5. Later
    Harden + eval. Reconnect with backoff, surface 1006/1011; then script 10 canned sessions and score them.Measure drops per 10 calls.

One-week sprint: Mon–Tue run + break it · Wed ship one starter · Thu–Fri attack one seam · Weekend 5-min demo.

Safety is a feature. The nurse template never gives medical advice, never predicts prognosis, and always defers to the care team — any template you write for sensitive domains must carry equivalent guardrails in its systemInstruction, and your eval (T6) must test them first.
